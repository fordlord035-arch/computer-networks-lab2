# Network_Router_Project — Практическая работа №2 (Вариант 3)

Программный маршрутизатор на Python. Моделирует взаимодействие нескольких
клиентов через две логические подсети (TCP и UDP) с приоритизацией трафика.

## Файлы

- `router.py` — программный маршрутизатор (TCP :5000, UDP :6000)
- `client_tcp.py` — TCP-клиент
- `client_udp.py` — UDP-клиент
- `clients.json` — таблица клиентов

## Клиенты (вариант 3)

| Клиент  | Протокол | Подсеть        | Приоритет |
|---------|----------|----------------|-----------|
| Client1 | TCP      | 192.168.1.0/24 | NORMAL    |
| Client2 | TCP      | 192.168.1.0/24 | NORMAL    |
| Client3 | TCP      | 192.168.1.0/24 | HIGH      |
| Client4 | UDP      | 192.168.2.0/24 | HIGH      |
| Client5 | UDP      | 192.168.2.0/24 | NORMAL    |
